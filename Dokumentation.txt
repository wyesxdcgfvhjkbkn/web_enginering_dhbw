📄 Dokumentation – Webapplikation Tower Defense
1. Einleitung
Im Rahmen dieses Projekts wurde eine webbasierte Anwendung zur Verwaltung und Darstellung eines Tower-Defense-Spiels entwickelt.
Ziel war es, eine moderne Single Page Application (SPA) mit Benutzeroberfläche, Benutzerverwaltung sowie Spielintegration umzusetzen.
Die Anwendung basiert auf React für das Frontend und kommuniziert über REST-Schnittstellen mit einem Backend-System.

2. Systemarchitektur
Die Anwendung folgt einer Client-Server-Architektur:
2.1 Frontend

Technologie: React (Vite)
Darstellung: HTML, CSS (Bootstrap)
Architektur: Single Page Application

2.2 Backend

Kommunikation über HTTP (REST API)
Endpunkte:

/login
/register
/highscore




3. Implementierung der Benutzeroberfläche
3.1 Framework
Für die Gestaltung der Benutzeroberfläche wurde das CSS-Framework Bootstrap 5 verwendet.
Dadurch wird ein responsives Design gewährleistet, welches sich an verschiedene Bildschirmgrößen anpasst.

3.2 Navigation
Die Anwendung besitzt eine zentrale Navigationsleiste (Navbar), die folgende Funktionen bereitstellt:

Navigation zu verschiedenen Seiten:

Anzeige des Benutzerstatus

Die Navbar wird dynamisch abhängig vom Login-Zustand angepasst:

4. Benutzerverwaltung
4.1 Registrierung
Die Registrierung erfolgt über ein Formular mit folgenden Feldern:

Name
E-Mail
Passwort
Passwort wiederholen

Validierung:

Alle Felder müssen ausgefüllt sein
E-Mail muss gültiges Format haben
Passwort ≥ 6 Zeichen
Passwortbestätigung muss übereinstimmen

Kommunikation:
JavaScriptfetch("http://localhost:3000/register", {  method: "POST",  headers: {    "Content-Type": "application/json",  },  body: JSON.stringify({    name,    email,    password,  }),});Weitere Zeilen anzeigen

4.2 Login
Der Login erfolgt über:

Benutzername oder E-Mail
Passwort

Ablauf:

Eingabe validieren
Anfrage an Backend senden
Benutzer im Frontend speichern (useState)
Navigation anpassen


4.3 Logout
Beim Logout:

Benutzer wird aus dem State entfernt
Navigation wird zurückgesetzt
